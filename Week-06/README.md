#  Health Care Data Analysis – Week 06

##  Project Overview

This project focuses on analyzing healthcare data using Python. The dataset is cleaned, processed, and analyzed to understand medical conditions, hospital stays, billing amounts, demographics, gender distribution, and insurance providers.

##  Objectives

* Load and explore the healthcare dataset
* Clean missing and invalid data
* Calculate hospital stay duration
* Analyze billing statistics
* Study patient demographics
* Analyze gender distribution
* Compare billing amounts across medical conditions and insurance providers
* Create visualizations for better understanding

##  Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

 Dataset

The project uses a healthcare dataset containing patient, medical condition, admission, discharge, billing, and insurance information.

 Data Analysis

The project performs:

* Dataset shape and summary analysis
* Missing-value detection and removal
* Date conversion
* Hospital stay calculation
* Billing statistics
* Age analysis by medical condition
* Gender distribution by medical condition
* Billing analysis by medical condition and insurance provider

 Visualizations

The project includes:

* Stacked bar chart for billing amounts by medical condition and insurance provider
* Violin plot for billing amount distribution by medical condition
* Violin plot for billing amount distribution by insurance provider

 Key Features

* Data preprocessing using Pandas
* Statistical analysis using descriptive statistics
* Grouping and aggregation of healthcare data
* Data visualization using Matplotlib and Seaborn

 How to Run

1. Open the Python file or Google Colab notebook.
2. Upload the healthcare dataset.
3. Make sure the dataset filename matches the file path used in the code.
4. Run the cells step by step.
5. View the analysis results and visualizations.
